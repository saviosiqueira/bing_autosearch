Tutorial
  1. Make sure you are signed into your Bing account.
  2. Start a new auto search by clicking the "Start Auto Search" button.
  3. To perform mobile searches, use a mobile device or emulate a mobile browser through the developer tools (F12) on the PC, or with an android emulator.
Limit
Interval
Randomized Intervals

Adds a random amount of time between each interval to avoid bot detection.

Background Audio

Plays a silent, looping audio track during the search to keep the site running in the background. Useful for mobile devices to keep the site running even while the device is sleeping/locked. Note: May not work with auto-start.

Multi-tab Mode

Opens each search in a new tab. For some devices/browsers this may be necessary to receive rewards points (enable if this is your case).
Be aware! To use the multi-tab mode, it's necessary to allow the opening of multiple tabs/pop-ups in your browser. Test

Auto-start Link

Gets a link that starts the auto search on page load with the configured settings. Useful for automating daily searches.
